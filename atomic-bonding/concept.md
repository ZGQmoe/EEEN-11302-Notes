# 12. Common Crystal Structures and Atomic Arrangements

## 12.1 Simple Cubic / SC

Simple cubic is the simplest cubic crystal structure.

### Arrangement

Atoms are placed only at the 8 corners of a cube.

```text
corner atoms only
```

Each corner atom is shared by 8 neighbouring unit cells.

So the number of atoms per unit cell is:

```math
8\times\frac{1}{8}=1
```

Therefore:

```math
\text{atoms per SC unit cell}=1
```

### Coordination Number

Each atom has 6 nearest neighbours:

- one in `+x`
- one in `-x`
- one in `+y`
- one in `-y`
- one in `+z`
- one in `-z`

```math
\text{coordination number}=6
```

### Packing

SC is not efficiently packed, so it is rare in real metals.

Only polonium is commonly cited as a metal with a simple cubic structure.

### Key Summary

| Feature | SC |
|---|---:|
| Unit cell shape | cube |
| Atom positions | corners only |
| Atoms per unit cell | 1 |
| Coordination number | 6 |
| Packing efficiency | low |
| Common materials | rare, e.g. Po |

Complete notes describe SC as a cubic unit cell with a 1-atom basis and one lattice point at `(0,0,0)`. The unit cell contains 1 atom in total because each corner atom contributes `1/8`, and each atom has 6 nearest neighbours. ## 12.2 Body-Centred Cubic / BCC

BCC stands for body-centred cubic.

### Arrangement

Atoms are placed at:

1. the 8 corners of the cube
2. one atom at the centre of the cube body

```text
corner atoms + one body-centre atom
```

The body-centre atom is completely inside the unit cell, so it counts as 1 full atom.

Corner contribution:

```math
8\times\frac{1}{8}=1
```

Body-centre contribution:

```math
1
```

Total:

```math
1+1=2
```

Therefore:

```math
\text{atoms per BCC unit cell}=2
```

### Lattice Point Positions

BCC can be described using lattice points at:

```math
(0,0,0)
```

and:

```math
\left(\frac{1}{2},\frac{1}{2},\frac{1}{2}\right)
```

The second point is exactly in the centre of the cube.

### Coordination Number

Each atom has 8 nearest neighbours.

```math
\text{coordination number}=8
```

This is because the atom at the centre is surrounded by 8 corner atoms.

### Packing

BCC is more closely packed than simple cubic, but less closely packed than FCC or HCP.

Typical metals with BCC structures include:

- Fe
- W
- Cr

### Key Summary

| Feature | BCC |
|---|---:|
| Unit cell shape | cube |
| Atom positions | corners + body centre |
| Lattice points | `(0,0,0)`, `(1/2,1/2,1/2)` |
| Atoms per unit cell | 2 |
| Coordination number | 8 |
| Common materials | Fe, W, Cr |

Complete notes describe BCC as a cubic unit cell with a 1-atom basis and 2 lattice points at `(0,0,0)` and `(1/2,1/2,1/2)`. The unit cell contains 2 atoms in total and each atom has 8 nearest neighbours.  [oai_citation:1‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

## 12.3 Face-Centred Cubic / FCC

FCC stands for face-centred cubic.

### Arrangement

Atoms are placed at:

1. the 8 corners of the cube
2. the centre of each of the 6 faces

```text
corner atoms + face-centred atoms
```

Corner contribution:

```math
8\times\frac{1}{8}=1
```

Each face-centred atom is shared by 2 unit cells, so each contributes:

```math
\frac{1}{2}
```

Face contribution:

```math
6\times\frac{1}{2}=3
```

Total:

```math
1+3=4
```

Therefore:

```math
\text{atoms per FCC unit cell}=4
```

### Lattice Point Positions

FCC lattice points are:

```math
(0,0,0)
```

```math
\left(0,\frac{1}{2},\frac{1}{2}\right)
```

```math
\left(\frac{1}{2},0,\frac{1}{2}\right)
```

```math
\left(\frac{1}{2},\frac{1}{2},0\right)
```

These correspond to one corner lattice point and three face-centred lattice points within the cubic unit cell.

### Coordination Number

Each atom has 12 nearest neighbours.

```math
\text{coordination number}=12
```

This high coordination number means FCC is very closely packed.

### Packing Factor

FCC has one of the highest packing factors:

```math
\text{packing factor}=74\%
```

This means 74% of the unit cell volume is occupied by atoms.

### Common Materials

Common FCC metals include:

- Cu
- Al
- Ni
- Ag
- Au

### Key Summary

| Feature | FCC |
|---|---:|
| Unit cell shape | cube |
| Atom positions | corners + face centres |
| Lattice points | `(0,0,0)`, `(0,1/2,1/2)`, `(1/2,0,1/2)`, `(1/2,1/2,0)` |
| Atoms per unit cell | 4 |
| Coordination number | 12 |
| Packing factor | 74% |
| Common materials | Cu, Al, Ni, Ag, Au |

Complete notes describe FCC as a cubic unit cell with a 1-atom basis and 4 lattice points at `(0,0,0)`, `(0,1/2,1/2)`, `(1/2,0,1/2)` and `(1/2,1/2,0)`. It contains 4 atoms per unit cell and each atom has 12 nearest neighbours.  [oai_citation:2‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

## 12.4 Why Metals Often Form BCC, FCC or HCP

Metals have metallic bonding.

Metallic bonding is non-directional, meaning atoms do not need to sit at fixed bond angles.

Therefore, positive ion cores can pack closely together inside the delocalised electron sea.

```math
\text{metallic bonding}
\rightarrow
\text{non-directional}
\rightarrow
\text{close packing}
```

This is why metals commonly form:

- BCC
- FCC
- HCP

FCC and HCP are especially close-packed.

The complete notes state that metals tend to form BCC or FCC because the electrostatic attraction between the electron cloud and positive ions forces the ions close together. FCC has a 74% packing factor, and metals can also form HCP structures.  [oai_citation:3‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

## 12.5 Hexagonal Close-Packed / HCP

HCP stands for hexagonal close-packed.

### Arrangement

HCP is based on close-packed layers of atoms.

The common stacking sequence is:

```math
ABABAB\cdots
```

This means:

- first layer: `A`
- second layer: `B`
- third layer: directly above the first layer `A`
- fourth layer: directly above the second layer `B`

So the layers alternate:

```text
A layer
B layer
A layer
B layer
...
```

### Hexagonal Cell

The conventional hexagonal cell contains:

- atoms at the corners of the top and bottom hexagons
- atoms at the centres of the top and bottom faces
- atoms in the middle layer

The complete notes state that the hexagonal cell contains 6 atoms in total: `1/6` atom at each corner for the bottom and top layers, `1/2` atom in the middle of the top and bottom layers, and 3 atoms in the middle layer.  [oai_citation:4‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

### Primitive Cell

The primitive rhombohedral unit cell contains 2 atoms.

The lattice points are:

```math
(0,0,0)
```

and:

```math
\left(\frac{2}{3},\frac{1}{3},\frac{1}{2}\right)
```

### Coordination Number

Each atom has 12 nearest neighbours.

```math
\text{coordination number}=12
```

### Packing Factor

HCP has the same maximum packing factor as FCC:

```math
\text{packing factor}=74\%
```

### Common Materials

Common HCP metals include:

- Mg
- Ti
- Zn
- Co

### Key Summary

| Feature | HCP |
|---|---:|
| Unit cell type | hexagonal / rhombohedral primitive cell |
| Layer stacking | ABAB |
| Atoms per conventional hexagonal cell | 6 |
| Atoms per primitive cell | 2 |
| Coordination number | 12 |
| Packing factor | 74% |
| Common materials | Mg, Ti, Zn, Co |

Complete notes state that HCP has a rhombohedral unit cell with a 1-atom basis and 2 lattice points at `(0,0,0)` and `(2/3,1/3,1/2)`, and like FCC, it has the highest packing factor of 74%.  [oai_citation:5‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

# 13. Covalent Semiconductor Crystal Structures

## 13.1 Why Covalent Solids Do Not Simply Close-Pack

Covalent bonding is directional.

This means atoms must sit at specific distances and angles.

Because of this, covalent solids do not simply pack as closely as possible.

Instead, their structure is controlled by bonding direction.

```math
\text{directional covalent bonding}
\rightarrow
\text{fixed bond angles}
\rightarrow
\text{diamond cubic / zincblende}
```

This is especially important for semiconductors such as:

- Si
- Ge
- GaAs
- InP

Complete notes state that covalent solids such as silicon and germanium form diamond cubic or zincblende structures because directional bonds force atoms to be positioned at set distances and angles.  [oai_citation:6‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

## 13.2 Diamond Cubic Structure

Diamond cubic is the structure of:

- diamond
- silicon
- germanium

### Arrangement

Diamond cubic can be thought of as an FCC lattice with a two-atom basis.

FCC lattice points:

```math
(0,0,0)
```

```math
\left(0,\frac{1}{2},\frac{1}{2}\right)
```

```math
\left(\frac{1}{2},0,\frac{1}{2}\right)
```

```math
\left(\frac{1}{2},\frac{1}{2},0\right)
```

Two-atom basis:

```math
(0,0,0)
```

and:

```math
\left(\frac{1}{4},\frac{1}{4},\frac{1}{4}\right)
```

Because the basis has two atoms and the FCC lattice has four lattice points per conventional unit cell:

```math
4\times2=8
```

Therefore:

```math
\text{atoms per diamond cubic unit cell}=8
```

### Bonding Arrangement

Each atom forms covalent bonds with 4 nearest neighbours.

```math
\text{coordination number}=4
```

The bonds form a tetrahedral arrangement.

```math
\text{bond angle}\approx109.5^\circ
```

### Why This Matters for Silicon

Silicon has four valence electrons.

Each silicon atom forms four covalent bonds.

```math
\text{Si has 4 valence electrons}
\rightarrow
\text{4 covalent bonds}
\rightarrow
\text{diamond cubic}
```

### Key Summary

| Feature | Diamond cubic |
|---|---:|
| Lattice type | FCC |
| Basis | two identical atoms |
| Basis positions | `(0,0,0)`, `(1/4,1/4,1/4)` |
| Atoms per unit cell | 8 |
| Coordination number | 4 |
| Bonding | tetrahedral covalent |
| Common materials | diamond, Si, Ge |

Complete notes describe diamond cubic as an FCC lattice with a two-atom basis at `(0,0,0)` and `(1/4,1/4,1/4)`, giving 8 atoms in each unit cell.  [oai_citation:7‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

## 13.3 Zincblende Structure

Zincblende is common for compound semiconductors such as:

- GaAs
- InP
- ZnS

### Arrangement

Zincblende is similar to diamond cubic.

The important difference is:

```math
\text{diamond cubic}
=
\text{two identical atoms in the basis}
```

```math
\text{zincblende}
=
\text{two different atoms in the basis}
```

For GaAs:

Two-atom basis:

```math
\text{As at }(0,0,0)
```

```math
\text{Ga at }\left(\frac{1}{4},\frac{1}{4},\frac{1}{4}\right)
```

So zincblende can be thought of as two interpenetrating FCC sublattices:

- one sublattice for one atom type
- another shifted sublattice for the other atom type

### Bonding Arrangement

Each atom is tetrahedrally bonded to 4 atoms of the opposite type.

For GaAs:

```math
\text{each Ga atom bonds to 4 As atoms}
```

```math
\text{each As atom bonds to 4 Ga atoms}
```

### Key Summary

| Feature | Zincblende |
|---|---:|
| Lattice type | FCC-like |
| Basis | two different atoms |
| Example basis | As at `(0,0,0)`, Ga at `(1/4,1/4,1/4)` |
| Coordination number | 4 |
| Bonding | tetrahedral, partly covalent / partly ionic |
| Common materials | GaAs, InP, ZnS |

Complete notes state that zincblende follows the diamond cubic structure but uses a basis of two different atoms. For GaAs, the basis consists of As at `(0,0,0)` and Ga at `(1/4,1/4,1/4)`.  [oai_citation:8‡Complete Lecture Note.pdf](sediment://file_00000000ef0871f4b7a892d91a08a3ef)

# 14. Ionic Crystal Structure: Rock Salt

## 14.1 Rock Salt / NaCl Structure

Rock salt is a common ionic crystal structure.

The key example is:

```math
\text{NaCl}
```

### Arrangement

NaCl consists of alternating positive and negative ions.

```math
\text{Na}^+
```

and:

```math
\text{Cl}^-
```

sit alternately throughout the crystal.

The structure can be described as an FCC lattice with a two-ion basis.

One common description is:

```math
\text{Cl}^- \text{ at }(0,0,0)
```

```math
\text{Na}^+ \text{ at }\left(\frac{1}{2},\frac{1}{2},\frac{1}{2}\right)
```

### Coordination Number

Each ion is surrounded by 6 nearest neighbours of the opposite charge.

For example:

```math
\text{each Na}^+
\text{ has 6 nearest Cl}^-
```

and:

```math
\text{each Cl}^-
\text{ has 6 nearest Na}^+
```

So:

```math
\text{coordination number}=6
```

### Why This Structure Forms

Ionic crystals try to maximise attraction between opposite charges and minimise repulsion between like charges.

```math
\text{maximise cation-anion attraction}
```

```math
\text{minimise cation-cation and anion-anion repulsion}
```

This produces a stable alternating ionic lattice.

### Key Summary

| Feature | Rock salt / NaCl |
|---|---:|
| Bonding | ionic |
| Arrangement | alternating cations and anions |
| Description | FCC with two-ion basis |
| Example basis | Cl at `(0,0,0)`, Na at `(1/2,1/2,1/2)` |
| Coordination number | 6 |
| Common materials | NaCl, MgO |

Complete notes describe NaCl as alternating Na+ and Cl- ions. It forms an FCC structure with a basis of Cl- at `(0,0,0)` and Na+ at `(1/2,1/2,1/2)`, and each ion has 6 nearest neighbours of opposite charge. # 15. Quick Comparison of Important Structures

| Structure | Main material type | Arrangement | Atoms per unit cell | Coordination number | Key reason |
|---|---|---|---:|---:|---|
| SC | rare metal | corners only | 1 | 6 | simple but inefficient packing |
| BCC | metals | corners + body centre | 2 | 8 | metallic bonding, relatively close packing |
| FCC | metals | corners + face centres | 4 | 12 | close-packed metallic structure |
| HCP | metals | ABAB close-packed layers | 6 conventional / 2 primitive | 12 | close-packed metallic structure |
| Diamond cubic | covalent semiconductors | FCC + two identical atom basis | 8 | 4 | tetrahedral covalent bonding |
| Zincblende | compound semiconductors | diamond-like, two different atoms | 8 conventional | 4 | tetrahedral compound bonding |
| Rock salt | ionic solids | alternating cations and anions | depends on cell description | 6 | maximise opposite-charge attraction |
